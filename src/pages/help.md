先开始基础阅读，实例和 AI 可以以后再考虑。Android 公开测试版已在[下载页](/download/)提供，完整发布验收仍在继续。

<h2 id="install">安装与更新</h2>

1. 从[下载页](/download/)下载测试版 APK，核对版本、文件大小与 SHA-256。官网中转入口不可用时可尝试 GitHub 备用下载。
2. 按 Android 提示为使用的浏览器或文件管理器允许安装来源；系统要求以下载页当前版本为准。
3. 使用同签名安装包覆盖升级，不要卸载或清除数据。升级包应同包名、同签名且 versionCode 更高；提前导出 OPML 和阅读状态，不同签名不能直接覆盖。

<h2 id="updates">手动检查更新</h2>

0.1.23/code24 已接通“设置 → 检查更新”：主动读取官方 GitHub 版本清单，发现新版后显示版本和更新说明，按“前往下载”在系统浏览器获取 APK。不需要 GitHub 账号，不自动下载、安装或后台检查。

0.1.22 及更早版本没有配置更新地址，首次请从[下载页](/download/)手动覆盖升级到最新测试版。当前 App 读取 GitHub 上的清单；网络不可达会显示失败，可稍后重试，不能据此认为已是最新版。官网清单同步版本信息，但不会自动改变旧安装包内的地址。

当前可在[下载页](/download/)查看测试版、校验值与下载入口。

## 添加自己的订阅

首次引导可以跳过，也可以选择发现目录中的订阅。以后从订阅管理手动添加可访问的 HTTPS RSS/Atom 地址，或导入 OPML：先看预览、确认条目与分组，再开始导入。部分失败会单独显示。

部分订阅由第三方服务生成，需确认服务地址、路由或公开 ID。有些授权由该服务完成；它与猫页的可选自有实例不同。猫页当前没有登录订阅源入口。

## 阅读、整理与全文

阅读页切换单源或全部订阅，使用日期与仅未读筛选；搜索已保存的标题、摘要，也可选择已保存原文正文。打开文章后可收藏、设为未读和调整阅读偏好。

有些订阅只提供摘要，获取全文会尝试从原网页提取正文，让你在猫页内继续阅读；效果受原站内容和访问限制影响。RSS 通常提供近期文章，首次订阅不保证获取全部历史。

## 主动保存单篇离线

文章页右上角“更多 → 保存离线”，选择是否包含正文图片。只保存已经取得的正文，不自动调用 AI 或获取全文。图片失败、容量或预算不足可能部分完成，以保存结果与实际张数为准，可重试未保存图片。

收藏与图文离线分开：收藏不自动下载全部图片。普通缓存可能被清理；主动离线副本独立保护。单图当前上限10 MiB、单篇20 MiB/50图、总离线预算300 MiB，正式包发布前复核。仅保存成功的内容能离线读取，不保存视频。

<h2 id="optional">可选：实例与 AI</h2>

### 自有实例

默认本机使用已经可以订阅和阅读。需要自己的后端时，在“设置 → 使用方式”连接自有实例，阅读数据按使用方式区分。不承诺自动同步所有设备，也不使用作者线上实例。

### AI 翻译与日摘要

在“设置 → AI 设置”填写自己选择的兼容服务、模型与密钥。翻译和日摘要主动触发后会发送所需文章文字，连接测试也会访问配置服务，供应商可能收费。日摘要针对选定单源、日期与可用文章集合，不是全网日报。结果须结合原文判断。

## 导出与数据管理

OPML 只包含订阅和分组；状态备份包含订阅 URL 与阅读标记，不包含正文、图文离线包、AI 结果或配置密钥。URL 本身可能带 token，文件请私密保存。卸载或重置会丢失本机数据，备份不等于完整设备备份。

## 遇到问题

图片、订阅与全文受原站和第三方服务限制；已有文字仍可阅读。先检查网络或原网页，再按实际失败提示重试。需要帮助时，请从[反馈入口](/feedback/)前往 GitHub Issues，附上版本、设备与重现步骤；不公开密钥、私人订阅 URL、账号或含个人内容的截图。安全问题使用私人漏洞报告。
